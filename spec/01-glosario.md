# Glosario

| Término | Significado |
|---|---|
| **Empresa emisora** | Razón social de Manya que emite el comprobante: *Templates* o *Manya Media*. Para rentabilidad se ven como una sola agencia. |
| **Cliente** | Razón social que contrata (con RUC cuando se conozca). |
| **Marca** | Marca comercial de un cliente. Un cliente puede tener varias. |
| **Categoría** | Agrupación de servicios (Performance, UX/UI, Soporte, Inbound…). |
| **Línea de negocio** | Agrupación de categorías para ver rentabilidad macro (Performance, Proyectos, Inbound). |
| **Servicio** | Ítem del catálogo (Plan Mensual, Pauta, Sitio web…). Define su categoría, su **modalidad** y su **naturaleza**. |
| **Modalidad** | *Mensual* (se repite por ciclos) o *Proyecto* (tiene fecha de inicio y de entrega). |
| **Naturaleza** | *Propio* (honorario de Manya) o *Terceros* (dinero que pasa a un tercero: pauta, influencers). |
| **Servicio contratado** | Acuerdo con un cliente para un servicio (p. ej. "Marca X – Plan Mensual"). Agrupa todos sus ciclos. Antes: "ID del servicio contratado". |
| **Venta** | Un ciclo de un servicio contratado (un mes) o un proyecto completo. Tiene fecha de contrato, monto neto (sin IGV) y moneda. Antes: fila de "Contratos". |
| **Periodo de servicio** | Mes en que se ejecuta una venta mensual. |
| **Cuota** | Parte planificada del pago de una venta (100% al inicio, 50% inicial, 50% final…). Antes: fila de "Plan de facturación". |
| **Comprobante** | Factura, boleta, recibo por honorarios o comanda emitida. Agrupa una o varias cuotas. |
| **Pago** | Dinero recibido en una cuenta, aplicado a una cuota. |
| **Detracción** | Parte del total (12%) que el cliente deposita en la cuenta del Banco de la Nación. |
| **Autodetracción** | Cuando el cliente pagó el 100% a la cuenta normal y Manya deposita la detracción por su cuenta. |
| **Ventas del mes** | Vista comercial: monto neto según **fecha de contrato**. Excluye terceros. |
| **Ingresos del mes** | Vista de devengado: monto neto según **mes de ejecución**. Excluye terceros. |
| **Comisión** | % del partner comercial sobre el neto de cada cuota; se gana cuando el comprobante queda pagado al 100%. |
| **GP (gross profit)** | Ingresos − costos asignados. Se mira de macro a micro: agencia → línea → equipo → cliente → venta. |
| **Cierre mensual** | Bloqueo de un mes: ya no se puede modificar y se fija su tipo de cambio. |
| **Anular** | Dejar sin efecto un registro con motivo. Nunca se borra. |

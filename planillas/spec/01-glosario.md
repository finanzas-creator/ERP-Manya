# Glosario · Planillas
| Término | Significado |
|---|---|
| **Empleador** | Entidad legal que paga la planilla (HoldingD y las demás). |
| **REMYPE** | Registro de la micro y pequeña empresa. Da el régimen laboral especial solo a quienes ingresan después de la inscripción. |
| **Régimen laboral** | *Micro*, *pequeña* o *general*: define gratificación, CTS, vacaciones e indemnización. |
| **Remuneración computable** | Lo que sirve de base para beneficios: básico + asignación familiar + fijos + variables regulares (y 1/6 de grati para la CTS). |
| **Novedades** | Lo que pasó en el mes: ausencias, horas extra, feriados trabajados, tardanzas, bonos, adelantos, descuentos. |
| **Provisión** | Parte del beneficio (grati, CTS, vacaciones) que se va ganando cada mes, aunque se pague después. |
| **Trunca** | Parte proporcional de un beneficio que se paga al cese, antes de completar el periodo. |
| **Adelanto de vacaciones** | Días de vacaciones gozados antes de ganarlos. |
| **Liquidación** | Pago de beneficios pendientes al cese (48 horas). |
| **Boleta** | Constancia de pago del mes que se entrega al trabajador. |
| **Código externo** | Identificador del trabajador en el ERP de control de personal (p. ej. H-07); une ambos sistemas. |
| **Anular** | Dejar sin efecto un registro con motivo. Nunca se borra. |
